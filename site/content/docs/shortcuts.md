On macOS, most shortcuts use <kbd>⌘</kbd> in place of <kbd>Ctrl</kbd>. The tables below list both forms.

## Files

| Action | Linux and Windows | macOS |
|---|---|---|
| New file | <kbd>Ctrl+N</kbd> | <kbd>⌘N</kbd> |
| New window | <kbd>Ctrl+Shift+N</kbd> | <kbd>⌘⇧N</kbd> |
| Open folder | <kbd>Ctrl+O</kbd> | <kbd>⌘O</kbd> |
| Open file by name | <kbd>Ctrl+P</kbd> | <kbd>⌘P</kbd> |
| Save | <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> |
| Save as | <kbd>Ctrl+Shift+S</kbd> | <kbd>⌘⇧S</kbd> |
| Close tab | <kbd>Ctrl+W</kbd> | <kbd>⌘W</kbd> |
| Reopen the closed tab | <kbd>Ctrl+Shift+T</kbd> | <kbd>⌘⇧T</kbd> |
| Next tab | <kbd>Ctrl+Tab</kbd> | <kbd>⌃Tab</kbd> |
| Previous tab | <kbd>Ctrl+Shift+Tab</kbd> | <kbd>⌃⇧Tab</kbd> |
| Open `settings.json` | <kbd>Ctrl+,</kbd> | <kbd>⌘,</kbd> |
| All commands | <kbd>Ctrl+Shift+P</kbd> | <kbd>⌘⇧P</kbd> |
| Quit | <kbd>Ctrl+Q</kbd> | <kbd>⌘Q</kbd> |

## Editing

| Action | Linux and Windows | macOS |
|---|---|---|
| Undo | <kbd>Ctrl+Z</kbd> | <kbd>⌘Z</kbd> |
| Redo | <kbd>Ctrl+Shift+Z</kbd> or <kbd>Ctrl+Y</kbd> | <kbd>⌘⇧Z</kbd> or <kbd>⌘Y</kbd> |
| Indent selected lines | <kbd>Tab</kbd> | <kbd>Tab</kbd> |
| Unindent selected lines | <kbd>Shift+Tab</kbd> | <kbd>⇧Tab</kbd> |
| Go to line | <kbd>Ctrl+G</kbd> | <kbd>⌘G</kbd> |
| Comment or uncomment lines | <kbd>Ctrl+/</kbd> | <kbd>⌘/</kbd> |
| Move lines up or down | <kbd>Alt+↑</kbd> / <kbd>Alt+↓</kbd> | <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> |
| Duplicate lines | <kbd>Shift+Alt+↑</kbd> / <kbd>Shift+Alt+↓</kbd> | <kbd>⇧⌥↑</kbd> / <kbd>⇧⌥↓</kbd> |
| Delete lines | <kbd>Ctrl+Shift+K</kbd> | <kbd>⌘⇧K</kbd> |
| Select line | <kbd>Ctrl+L</kbd> | <kbd>⌘L</kbd> |
| Delete a word | <kbd>Ctrl+Backspace</kbd> / <kbd>Ctrl+Delete</kbd> | <kbd>⌥⌫</kbd> / <kbd>⌥⌦</kbd> |

Undo and redo group changes by word.

## Cursors

| Action | Linux and Windows | macOS |
|---|---|---|
| Select the next occurrence | <kbd>Ctrl+D</kbd> | <kbd>⌘D</kbd> |
| Select every occurrence | <kbd>Ctrl+Shift+L</kbd> | <kbd>⌘⇧L</kbd> |
| Add a cursor above or below | <kbd>Ctrl+Alt+↑</kbd> / <kbd>Ctrl+Alt+↓</kbd> | <kbd>⌘⌥↑</kbd> / <kbd>⌘⌥↓</kbd> |
| Add or remove a cursor | <kbd>Alt</kbd>+click | <kbd>⌥</kbd>+click |
| Back to one cursor | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

## File tree and view

| Action | Linux and Windows | macOS |
|---|---|---|
| Rename | <kbd>F2</kbd> | <kbd>F2</kbd> |
| Move to the trash | <kbd>Delete</kbd> | <kbd>⌦</kbd> |
| Cut, copy, paste in the tree | <kbd>Ctrl+X</kbd>, <kbd>Ctrl+C</kbd>, <kbd>Ctrl+V</kbd> | <kbd>⌘X</kbd>, <kbd>⌘C</kbd>, <kbd>⌘V</kbd> |
| Show or hide the sidebar | <kbd>Ctrl+B</kbd> | <kbd>⌘B</kbd> |
| Markdown preview | <kbd>Ctrl+Shift+V</kbd> | <kbd>⌘⇧V</kbd> |
| Show or hide the terminal | <kbd>Ctrl+`</kbd> | <kbd>⌃`</kbd> |
| New terminal | <kbd>Ctrl+Shift+`</kbd> | <kbd>⌃⇧`</kbd> |
| Move the tab to the other side | <kbd>Ctrl+\</kbd> | <kbd>⌘\</kbd> |
| Bigger / smaller / original font | <kbd>Ctrl+=</kbd> / <kbd>Ctrl+-</kbd> / <kbd>Ctrl+0</kbd> | <kbd>⌘=</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> |

In the terminal, <kbd>Ctrl+Shift+C</kbd> and <kbd>Ctrl+Shift+V</kbd> copy and paste, and the other <kbd>Ctrl</kbd> keys go to the program. <kbd>Ctrl</kbd>+click on a file location opens it.

On Mac keyboards without a <kbd>⌦</kbd> key, press <kbd>Fn+Delete</kbd>.

Shortcuts cannot be changed. BIA reads them by key position, so they also work with non-Latin keyboard layouts.
