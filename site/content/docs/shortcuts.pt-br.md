No macOS, a maioria dos atalhos usa <kbd>⌘</kbd> no lugar de <kbd>Ctrl</kbd>. As tabelas abaixo mostram as duas formas.

## Arquivos

| Ação | Linux e Windows | macOS |
|---|---|---|
| Abrir pasta | <kbd>Ctrl+O</kbd> | <kbd>⌘O</kbd> |
| Abrir arquivo pelo nome | <kbd>Ctrl+P</kbd> | <kbd>⌘P</kbd> |
| Salvar | <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> |
| Fechar aba | <kbd>Ctrl+W</kbd> | <kbd>⌘W</kbd> |
| Próxima aba | <kbd>Ctrl+Tab</kbd> | <kbd>⌃Tab</kbd> |
| Aba anterior | <kbd>Ctrl+Shift+Tab</kbd> | <kbd>⌃⇧Tab</kbd> |
| Abrir o `settings.json` | <kbd>Ctrl+,</kbd> | <kbd>⌘,</kbd> |

## Edição

| Ação | Linux e Windows | macOS |
|---|---|---|
| Desfazer | <kbd>Ctrl+Z</kbd> | <kbd>⌘Z</kbd> |
| Refazer | <kbd>Ctrl+Shift+Z</kbd> ou <kbd>Ctrl+Y</kbd> | <kbd>⌘⇧Z</kbd> ou <kbd>⌘Y</kbd> |
| Indentar as linhas selecionadas | <kbd>Tab</kbd> | <kbd>Tab</kbd> |
| Remover a indentação das linhas selecionadas | <kbd>Shift+Tab</kbd> | <kbd>⇧Tab</kbd> |
| Ir para a linha | <kbd>Ctrl+G</kbd> | <kbd>⌘G</kbd> |
| Comentar ou descomentar linhas | <kbd>Ctrl+/</kbd> | <kbd>⌘/</kbd> |
| Mover linhas para cima ou para baixo | <kbd>Alt+↑</kbd> / <kbd>Alt+↓</kbd> | <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> |
| Duplicar linhas | <kbd>Shift+Alt+↑</kbd> / <kbd>Shift+Alt+↓</kbd> | <kbd>⇧⌥↑</kbd> / <kbd>⇧⌥↓</kbd> |
| Apagar linhas | <kbd>Ctrl+Shift+K</kbd> | <kbd>⌘⇧K</kbd> |
| Selecionar a linha | <kbd>Ctrl+L</kbd> | <kbd>⌘L</kbd> |
| Apagar uma palavra | <kbd>Ctrl+Backspace</kbd> / <kbd>Ctrl+Delete</kbd> | <kbd>⌥⌫</kbd> / <kbd>⌥⌦</kbd> |

Desfazer e refazer agrupam as alterações por palavra.

## Cursores

| Ação | Linux e Windows | macOS |
|---|---|---|
| Selecionar a próxima ocorrência | <kbd>Ctrl+D</kbd> | <kbd>⌘D</kbd> |
| Selecionar todas as ocorrências | <kbd>Ctrl+Shift+L</kbd> | <kbd>⌘⇧L</kbd> |
| Pôr um cursor acima ou abaixo | <kbd>Ctrl+Alt+↑</kbd> / <kbd>Ctrl+Alt+↓</kbd> | <kbd>⌘⌥↑</kbd> / <kbd>⌘⌥↓</kbd> |
| Pôr ou tirar um cursor | <kbd>Alt</kbd>+clique | <kbd>⌥</kbd>+clique |
| Voltar a um cursor só | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

## Busca

| Ação | Linux e Windows | macOS |
|---|---|---|
| Buscar | <kbd>Ctrl+F</kbd> | <kbd>⌘F</kbd> |
| Próximo resultado | <kbd>F3</kbd> | <kbd>F3</kbd> |
| Resultado anterior | <kbd>Shift+F3</kbd> | <kbd>⇧F3</kbd> |
| Substituir | <kbd>Ctrl+H</kbd> | <kbd>⌘⌥F</kbd> |
| Buscar nos arquivos | <kbd>Ctrl+Shift+F</kbd> | <kbd>⌘⇧F</kbd> |
| Voltar para a árvore de arquivos | <kbd>Ctrl+Shift+E</kbd> | <kbd>⌘⇧E</kbd> |

## Servidores de linguagem

| Ação | Linux e Windows | macOS |
|---|---|---|
| Ir para a definição | <kbd>F12</kbd> ou <kbd>Ctrl</kbd>+clique | <kbd>F12</kbd> ou <kbd>⌘</kbd>+clique |
| Completar | <kbd>Ctrl+Space</kbd> | <kbd>⌃Space</kbd> |
| Formatar o arquivo | <kbd>Shift+Alt+F</kbd> | <kbd>⇧⌥F</kbd> |
| Renomear o símbolo | <kbd>F2</kbd> no editor | <kbd>F2</kbd> no editor |
| Próximo / anterior problema | <kbd>F8</kbd> / <kbd>Shift+F8</kbd> | <kbd>F8</kbd> / <kbd>⇧F8</kbd> |

## Árvore de arquivos e exibição

| Ação | Linux e Windows | macOS |
|---|---|---|
| Novo arquivo | <kbd>Ctrl+N</kbd> | <kbd>⌘N</kbd> |
| Nova pasta | <kbd>Ctrl+Shift+N</kbd> | <kbd>⌘⇧N</kbd> |
| Renomear | <kbd>F2</kbd> | <kbd>F2</kbd> |
| Mover para a lixeira | <kbd>Delete</kbd> | <kbd>⌦</kbd> |
| Mostrar ou esconder a barra lateral | <kbd>Ctrl+B</kbd> | <kbd>⌘B</kbd> |
| Prévia de Markdown | <kbd>Ctrl+Shift+V</kbd> | <kbd>⌘⇧V</kbd> |
| Mostrar ou esconder o terminal | <kbd>Ctrl+`</kbd> | <kbd>⌃`</kbd> |
| Fonte maior / menor / original | <kbd>Ctrl+=</kbd> / <kbd>Ctrl+-</kbd> / <kbd>Ctrl+0</kbd> | <kbd>⌘=</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> |

No terminal, <kbd>Ctrl+Shift+C</kbd> e <kbd>Ctrl+Shift+V</kbd> copiam e colam, e as outras teclas com <kbd>Ctrl</kbd> vão para o programa.

Em teclados Mac sem a tecla <kbd>⌦</kbd>, use <kbd>Fn+Delete</kbd>.

Os atalhos não podem ser alterados. O BIA os identifica pela posição das teclas, então eles também funcionam em layouts de teclado não latinos.
