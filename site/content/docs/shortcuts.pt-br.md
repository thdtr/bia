No macOS, a maioria dos atalhos usa <kbd>⌘</kbd> no lugar de <kbd>Ctrl</kbd>. As tabelas abaixo mostram as duas formas.

## Arquivos

| Ação | Linux e Windows | macOS |
|---|---|---|
| Abrir pasta | <kbd>Ctrl+O</kbd> | <kbd>⌘O</kbd> |
| Abrir arquivo pelo nome | <kbd>Ctrl+P</kbd> | <kbd>⌘P</kbd> |
| Salvar | <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> |
| Fechar aba | <kbd>Ctrl+W</kbd> | <kbd>⌘W</kbd> |
| Próxima aba | <kbd>Ctrl+Tab</kbd> | <kbd>⌃Tab</kbd> |
| Aba anterior | <kbd>Ctrl+Shift+Tab</kbd> | <kbd>⌃⇧Tab</kbd> |
| Abrir o `settings.json` | <kbd>Ctrl+,</kbd> | <kbd>⌘,</kbd> |

## Edição

| Ação | Linux e Windows | macOS |
|---|---|---|
| Desfazer | <kbd>Ctrl+Z</kbd> | <kbd>⌘Z</kbd> |
| Refazer | <kbd>Ctrl+Shift+Z</kbd> ou <kbd>Ctrl+Y</kbd> | <kbd>⌘⇧Z</kbd> ou <kbd>⌘Y</kbd> |
| Indentar as linhas selecionadas | <kbd>Tab</kbd> | <kbd>Tab</kbd> |
| Remover a indentação das linhas selecionadas | <kbd>Shift+Tab</kbd> | <kbd>⇧Tab</kbd> |
| Ir para a linha | <kbd>Ctrl+G</kbd> | <kbd>⌘G</kbd> |

Desfazer e refazer agrupam as alterações por palavra.

## Busca

| Ação | Linux e Windows | macOS |
|---|---|---|
| Buscar | <kbd>Ctrl+F</kbd> | <kbd>⌘F</kbd> |
| Próximo resultado | <kbd>F3</kbd> | <kbd>F3</kbd> |
| Resultado anterior | <kbd>Shift+F3</kbd> | <kbd>⇧F3</kbd> |
| Substituir | <kbd>Ctrl+H</kbd> | <kbd>⌘⌥F</kbd> |

## Árvore de arquivos e exibição

| Ação | Linux e Windows | macOS |
|---|---|---|
| Novo arquivo | <kbd>Ctrl+N</kbd> | <kbd>⌘N</kbd> |
| Nova pasta | <kbd>Ctrl+Shift+N</kbd> | <kbd>⌘⇧N</kbd> |
| Renomear | <kbd>F2</kbd> | <kbd>F2</kbd> |
| Mover para a lixeira | <kbd>Delete</kbd> | <kbd>⌦</kbd> |
| Mostrar ou esconder a barra lateral | <kbd>Ctrl+B</kbd> | <kbd>⌘B</kbd> |
| Prévia de Markdown | <kbd>Ctrl+Shift+V</kbd> | <kbd>⌘⇧V</kbd> |

Em teclados Mac sem a tecla <kbd>⌦</kbd>, use <kbd>Fn+Delete</kbd>.

Os atalhos não podem ser alterados. O BIA os identifica pela posição das teclas, então eles também funcionam em layouts de teclado não latinos.
